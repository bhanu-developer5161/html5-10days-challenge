# Day 3 - HTML Tables

## Tags Learned

- <table> - Creates a table
- <tr> - Table row
- <th> - Table header
- <td> - Table data
- <caption> - Table title
- <thead> - Table header section
- <tbody> - Table body
- <tfoot> - Table footer

## Attributes

- border
- cellpadding
- cellspacing
- rowspan
- colspan

## Key Points

- Use <th> for headings.
- Use <td> for data cells.
- Use <caption> to describe the table.
- <thead>, <tbody>, and <tfoot> organize table content.
- rowspan merges cells vertically.
- colspan merges cells horizontally.
